# # Internet-Profile

A centralized portfolio platform that allows developers to upload and showcase projects of different types in a single file. It enables developers to track, manage, and display their work effortlessly.

## Features
- **AI Prompt Generator:** An integrated tool that assists users in writing high-quality AI prompts (like a senior developer) and makes project prompts reusable for new developers.
- **Project Showcase:** A clean, responsive UI to display web and mobile app projects.
- **Developer Links:** Direct links to live web apps, marketer portals, and Play Store apps.

## Tech Stack
- HTML5 & Tailwind CSS (UI & Styling)
- Vanilla JavaScript (Logic)
- Gemini API (AI Prompt Generation)
